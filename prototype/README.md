# 智能随访 v10 原型

可点击 HTML 原型 — 给医院客户/医生预览, 决定 UI 方向后再实施小程序代码.

## 怎么打开

### A. VSCode + Live Preview / Pencil 类插件
1. VSCode 打开 `prototype/index.html`
2. 右键 → "Show Preview" / "Open with Live Preview" / "Open in Pencil"
3. 即可看到 iPhone 尺寸 (375x812) 的小程序原型

### B. 浏览器
直接双击 `prototype/index.html` 即可

### C. 真机 (Android / iOS) 扫码看
1. 起本地 server: `cd prototype && python3 -m http.server 8080`
2. 看 WSL/Windows IP: `ipconfig` 或 `ip addr | grep inet`
3. 手机和电脑同一 WiFi → 浏览器输 `http://<电脑IP>:8080`
4. iOS 可以"添加到主屏幕"伪装成 App

## 设计要点

- **iPhone 14 尺寸** (375×812) 模拟真机视觉
- **4-Tab 架构**: 首页 / 测量 / 数据 / 我的
- **医疗专业蓝** #2c6ef2 主色 + 警示红/成功绿/提示橙
- **卡片化** 所有内容块圆角 12-14px + 柔和阴影
- 渐变状态条 (135deg) 视觉焦点突出

## 4 个 Tab 速览

### Tab 1: 首页
- 当前患者卡 (蓝/红渐变)
- 蓝牙连接卡 (绿/红渐变)
- 4 个常用大按钮: 血压 / 心率 / 血氧 / 体温
- 今日采集统计 (3 个数字)
- 最近测量 (5 条历史)

### Tab 2: 测量
- 顶部当前患者标识条 (薄)
- 三个分组:
  - 常规体征 (5 项): 血压 / 心率 / 血氧 / 体温 / 血糖
  - 进阶 (4 项): ECG / PTT / 血液成分 / 身体成分
  - 综合 (3 项): 日常 / 睡眠 / 计步

### Tab 3: 数据
- 顶部患者切换 chip (横向滑动)
- 3 个统计数字 (血压/心率/异常)
- 趋势图 (假数据柱状图, 实施时改 ECharts/F2)
- 异常数据列表
- 导出按钮 (CSV / PDF / 分享)

### Tab 4: 我的
- 设备 (扫描 / 重连 / 断开 / OTA)
- 患者管理 (当前 / 列表)
- 偏好 (单位 / 提醒 / 表盘)
- 关于 (版本 / 使用说明)
- 调试 (正式版隐藏)

## 与当前小程序的差异

| 维度 | 现状 (v10) | 原型 (v10) |
|---|---|---|
| 信息架构 | 单页 25+ 按钮宫格 | 4-tab 分类 |
| 患者管理 | 仅一条状态条 | 患者中心化, Tab 2/3 顶部都有切换条 |
| 数据视图 | ❌ 没有 | ✅ Tab 3 趋势图 + 异常列表 + 导出 |
| 调试入口 | 跟功能混在一起 | 折叠到 Tab 4 末尾 + 正式版隐藏 |
| 视觉风格 | v10 已渐变化 | 沿用 v10 + 强化卡片层级 |
