====================
    设备在网状态
====================
本文档说明设备在网状态的概念和如何获取设备在网状态。

------------------------
    什么是设备在网状态
------------------------
设备在网状态，是指设备是否已经连入物联网平台，连上是在线，没连上则是离线。设备在网状态不必然说明设备是否能联网，
但离线状态下的设备，无法给它发送任何指令。

------------------------
    如何获取设备在网状态
------------------------
需要开发一个接口，和接受设备上传数据的接口在一个程序里，当设备的在网状态发生改变，如在线到离线，离线到在线，我们
的系统会调用这个接口，上传当前设备在网状态:

设备上线 ::

{"DeviceId":"869595061621362","EventTime":"2024-10-23 05:23:30","Status":"online"}

设备离线 ::

{"DeviceId":"869595061621362","EventTime":"2024-10-23 10:43:30","Status":"offline"}

这个接口的示例代码（包括route）已经包括在我们提供的sample api里，可以参考。

这个功能需要找我们申请，并提供您API程序的Host, 不包括后面route部分。
