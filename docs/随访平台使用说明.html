①平台是什么

一句话讲清楚:随访平台把患者身上三条设备链路产生的数据,按"人"串起来看。

患者的体征数据来自三条互相独立的设备链路(iwown 4G 手表 / S101·R04 蓝牙手表和戒指 / 诊脉仪),以前只能分别去三个看板里按设备找数据。随访平台把这三条链路"绑"到同一个患者名下,医护打开一个页面,就能看到这个患者是谁、最近体征怎么样、这几天有没有好好戴设备、有没有报警要处理 — 不用再挨个看板去核对同一个人。

链路患者/设备端怎么用医护需要做的事
iwown 4G 手表 患者直接戴上即可,4G 蜂窝网络直连服务器自动上传,全程免操作(不用装小程序、不用带手机) 建档后在"绑定/解绑"里填设备号(15 位)
S101 / R04(蓝牙手表/戒指) 需要患者(或家属)手机装微信小程序,打开小程序把手表连上才会采数据 无需单独绑定,小程序里录入的门诊号与建档门诊号一致即自动归户
诊脉仪 医护现场检测,导出 .zip 后在诊脉仪看板里解析、确认入库 建档时把患者的诊脉仪病例号(case_id)在"绑定/解绑"里填进去

②快速上手

打开链接即用,写操作首次需要一次性输入口令。

打开方式:浏览器或手机直接打开 https://qqyjx.github.io/suifang/prototype/platform.html,不用装 App、不用登录账号。

看数据不用口令:浏览患者列表、患者详情、报警列表都是只读浏览,直接看就行。

写操作第一次会要口令:第一次点 ＋ 建档 保存、绑定/解绑 提交,或在报警工作台里点处理按钮时,页面会弹出一个访问口令输入框。这个口令向平台管理员肖逸凡索取,填一次之后浏览器会记住,同一台设备/浏览器以后不用再填(除非清了浏览器数据或换了新设备/新浏览器)。

③患者建档与设备绑定

先建档,再把设备/病例号绑到这个患者名下。

3.1 建档

  1. 患者列表页右上角点 ＋ 建档
  2. 门诊号(patient_no, 主键) * 必填 — 务必与 HIS 门诊号完全一致。这是绑定和查询这个患者的唯一依据,填错、多个空格或大小写不一致,都会导致设备数据对不上人
  3. 姓名 / 性别 / 年龄 / 分组(队列) / 备注 按需填写,都可以之后再补
  4. 点 保存
已建档患者想改信息,在该患者卡片下方点 改档,同一个弹窗改完再点保存即可(门诊号本身建档后不能改)。

3.2 绑定 / 解绑设备

  1. 患者卡片下方点 绑定/解绑
  2. 下拉框"链路"里选 iwown 4G 手表 (key = device_id) 或 诊脉仪 (key = case_id)
  3. iwown:在下面输入框填15 位设备号(手表表底或包装上能看到,格式类似 DEVWATCH00000001);诊脉仪:填诊脉仪病例号(case_id)
  4. 点 提交

S101/R04 不需要在这里绑定 — 只要小程序里录入的门诊号跟建档门诊号一致,数据会自动归到这个患者名下。

绑错了怎么办:直接重新绑定即可。同一个设备号/病例号再绑给另一个患者,会把这台设备迁移到新患者名下,原来那个患者的卡片上就不会再显示这台设备的数据了。如果只是想解除绑定而不换人,勾选 解绑 (清空该链路绑定) 后点提交即可。

④看患者数据

患者列表看概况,点进详情页看趋势和依从性。

4.1 患者列表卡片各元素

  • 佩戴率环:圆环 + 百分比,是这个患者近 7 天 iwown 手表的平均佩戴率;显示"--"代表还没绑 iwown 设备,或没有佩戴数据(不是佩戴率为 0)
  • 绑定徽标:iwown / S101·R04 / 诊脉仪 三个小标签,打勾 = 已绑定,叉号 = 未绑定
  • 报警角标:卡片右上角红色 ⚠ 数字,是这个患者当前待处理/进行中的报警条数,点一下会直接跳到报警工作台并筛选出这个患者
  • 最近上传:iwown / S101 各自最近一次收到数据的时间,长时间没更新可能是设备离线或没戴

4.2 患者详情页

点开患者卡片进详情页,顶部有 7 天 / 14 天 / 30 天 三个切换按钮,决定下面所有图表和统计的时间窗口。

  • 五类体征趋势图:心率(bpm)/血氧(%)/血压(mmHg)/体温(℃)/步数(步/日),iwown 和 S101 两条链路的数据画在同一张图上对比(用图例颜色区分)
  • 佩戴依从性明细条:每天一根柱子,柱高 = 当天佩戴覆盖的小时数 / 24 小时,柱子越高说明这天戴的时间越长;柱子顶上出现 ⚠ 数字 代表当天有对应次数的"未佩戴"报警,可以跟柱子矮的那几天对照着看
  • 报警时间线:这个患者最近的报警记录,只读摘要,点了会跳去报警工作台处理
  • 设备状态条:iwown 设备的电量/信号/最近在线时间,诊脉仪最近一次的体质结论和主脉象

⑤报警处理

工作台集中处理所有患者的报警,危急报警优先。

入口:患者列表右上角点 🚨 报警工作台(角标数字是全平台当前未处理报警总数);也可以从某个患者的报警角标或详情页"报警时间线"点进去,会自动带上这个患者的筛选。

5.1 状态含义

页签含义
待处理报警刚发生,还没人看过
已知晓医护已经看到、确认知道了
已回访已联系/上门过患者,记录过回访结果
已关闭这条报警处理完毕,归档
全部不筛选状态,看所有历史报警

5.2 处理流程

点开一条报警会弹出处理框:

  1. 填 操作人(填一次会记住,下次自动带出)
  2. 先点 ✓ 知晓,确认收到这条报警(待处理 → 已知晓)
  3. 电话或上门联系患者后,"回访方式"选 电话 / 上门,在"处理/回访结果"里写清楚联系情况,点 📞 记录回访(状态变为已回访;这一步可以重复多次记录,比如打了两次电话都能分别记一条)
  4. 确认这件事处理完了,点 ✕ 关闭(转为已关闭)
优先级:跌倒 和 SOS 是最高等级(红色圆点标记),要优先处理;心率/血氧/血压/体温越限是黄色提示,久坐/未佩戴/低电量是灰色提示,优先级依次降低。
报警不是实时到账的:手表触发报警后,服务器每 10 分钟自动扫一次原始数据、生成报警记录,不需要人工点什么按钮。如果着急想马上看到最新报警,可以点右上角 ⟳ 拉取新报警 手动触发一次。

⑥常见问题

遇到问题先翻这里,答案都对照系统实际行为写的。

口令(访问令牌)忘了怎么办?
向平台管理员肖逸凡重新索取,在下次做写操作时弹出的框里填入即可。填过一次浏览器会记住,不用每次都问,也不用自己找地方保存。
患者建档了,但看不到他的手表/诊脉仪数据?
先检查是否已做过"绑定/解绑"(iwown、诊脉仪都要绑,S101 靠门诊号自动归户);再确认门诊号跟建档时填的完全一致,哪怕多一个空格或大小写不同都算对不上号。
佩戴率为什么显示很低,或者一直是"--"?
佩戴率只统计 iwown 4G 手表当天有数据覆盖的小时数(0~24 小时),S101/诊脉仪不参与这个统计。没绑 iwown 设备的患者,佩戴率环固定显示"--",代表没有数据可算,不是佩戴率为 0。
手表明明报警了,报警工作台里怎么没看到?
报警不是实时到账的,服务器每 10 分钟自动扫一次原始数据才会生成报警记录。着急的话点报警工作台右上角"⟳ 拉取新报警"手动刷新一次就能看到最新的。
手机能用这个平台吗?
能。它是普通网页,手机、平板、电脑浏览器直接打开链接就行,页面对手机屏幕做过适配,不需要装 App 或小程序(S101/R04 的数据采集本身仍需要患者那边装小程序连手表,平台本身不用)。
页面上的数据多久更新一次?
患者列表和详情页不会自动刷新,需要手动点"⟳ 刷新"或重新打开页面才能看到最新数据;报警记录后台每 10 分钟自动生成,但工作台列表同样要手动刷新或切换页签才会显示出来。
报警状态点错了,或者忘了记一条回访内容,怎么办?
状态只能往前推进(待处理 → 已知晓 → 已回访 → 已关闭),不能回退,但同一条报警可以反复点"📞 记录回访"补充多条处理记录,之前几次的回访内容都会保留在处理记录里,随时能翻看核对。
