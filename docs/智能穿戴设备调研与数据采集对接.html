① 短期 1.0

我们手上已有 4 款设备、3 条数据链路,其中 iwown 4G 手表与诊脉仪均持二类医疗器械注册证。iwown 全链路已上线,心率、血氧、血压、体温、步数等核心体征已入库,随访平台对接只差患者绑定和看板接入两步。

国内拿到二类医疗器械证的手表、手环、戒指逐一盘点:谁有证、证管什么功能、能采到什么数据、有没有企业级数据接口。为采购成品和对标定价提供依据。

1.3 与随访平台的对接清单(1.0 落地四步)

  1. 患者绑定:iwown_device 表已预留 patient_no 字段,后台把设备号与门诊号绑定,数据即归到患者名下。与 S101 门诊号体系同构,可复用绑定页面。
  2. 看板接入:原型 iwown-dashboard.html 已有三看板雏形,把 iwown_data 体征列接入随访平台患者视图,入组后自动展示趋势。
  3. 报警工作流:解析 0x12 报警帧入事件表,跌倒 / SOS / 体征越限推送随访工作台,形成「报警 → CRC 回访 → 记录」闭环。报警阈值经下发指令可配。
  4. 佩戴依从性:用未佩戴报警 + 设备在线状态做佩戴率统计,纳入随访质量指标。
与 06-09 会议的衔接:会议明确轻量平台核心是信息采集,覆盖入组前中后。穿戴设备链路就是其中「被动连续采集」的入口,与 AI 语音转结构化、OCR 病历识别并列为三类采集方式。本章 A 表字段可直接作为轻量平台 1.0 设计方案中「智能穿戴数据采集入口」的字段清单。

③深圳代工与六元 2.0 硬件路径

结论速览:深圳及珠三角集中了全国约六到七成的智能手表手环 ODM 产能,从百台贴牌到百万级 ODM 全梯度都有,供给侧不是瓶颈。现有供应商埃微本身就是 ODM 出身,累计代工出货约 1100 万只,且已转型智慧养老 4G 健康手表方向,与我们场景高度同构,2.0 第一站应先谈埃微深度定制,而不是急着换厂。医疗器械注册人制度 MAH 已全国落地,「六元持证 + 工厂委托生产」路径法规上完全打通。

3.4 医疗器械注册人制度 MAH:自有二类证怎么拿

制度框架:注册人制度允许「持证」和「生产」分离。六元作为注册人申报二类证,委托持有相应生产许可的工厂生产;注册人对设计开发、临床、生产、销售、不良事件全生命周期负全责,双方签质量协议。国家药监局 2024 年 38 号公告进一步收紧委托生产监管,注册人自身要建质量管理能力,不是出钱挂名。移动与可穿戴医疗器械有专门审查指导原则(2025 修订版),软件与网络安全资料按此准备。

环节周期 / 费用备注
形式审查 + 技术审评约 20 个工作日 + 60-90 个工作日各省略有差异

3.5 两个形态的成熟度判断

4G 健康手表公板 成熟,1.5 阶段首选

芯片平台高度成熟:紫光展锐 W307/W317/W117 等专为 4G 手表设计,集成 4G + 蓝牙 + WiFi + GNSS,官方面向儿童老人手表场景。市面康养公板普遍带 GPS 多重定位、双向通话、SOS、电子围栏、跌倒报警、心率血压趋势血氧。贴牌不动模具,主要花费在 logo、包装、固件参数和数据接口对接。深圳可谈的:埃微、联硕、博实结,星迈聚伟询价确认。

智能戒指 ODM 可做,但当不了随访主终端

2025 上半年全球出货 160 万枚,深圳是全球戒指供应链中心。可接 ODM 的有魔样、易优斯、联硕及友宏、雅为、凌拓、玖智等方案商。消费级方案(睡眠 HRV 血氧)成熟可贴牌,但戒指无屏、无蜂窝、依赖手机,做不了 4G 直传和主动报警,除 RingConn 外几乎无人拿医疗证。定位:2.5 阶段夜间睡眠与依从性补充采集。

4.1 五步路线

  1. 1.0(本周内可动):完成 iwown 链路三件事 — 患者绑定、看板接入随访平台、0x12 报警帧解析进工作台。同步向 iwown 索取 EntService 凭据和该型号注册证信息,真机核字段。这就是 06-09 会议要的「数据采集入口」初稿落点。
  2. 1.0+(与 1.0 并行,按病种选配):高血压心血管随访试点华为 WATCH D2 + Health Kit 企业 API;血氧呼吸类随访批量发乐普 O2Ring。用获证成品先把「医疗级数据进平台」跑通,不必等自有硬件。
  3. 1.5(0-6 个月,公板贴牌):首选与埃微谈 H102C / H103 公板品牌定制 + IoT 平台直连六元后台,1.0 平滑升级零迁移;同步约谈联硕智能(私有化后台是现成的)和星迈(100 台门槛)比价备份。目标百台到千台级,融资 demo + 试点落地。产品页规范表述为「健康管理参考,非医疗诊断」。
  4. 2.0(6-18 个月,ODM 半定制):在 Veepoo(医疗算法强)、爱都(量产强)、领为(技术栈新)、联硕(后台配套强)中选 1-2 家开私模:独占外观 + 定制固件(随访提醒、用药打卡、跌倒调参)+ 数据协议直连,签外观独占与数据归属条款。同期找 CRO 对照免临床目录做预审,确定先拿哪个单指标(血氧脉率最常见),注册检验前置。
  5. 3.0(18 个月+,MAH 自有证):六元作为注册人申报二类证(优先单指标),委托持生产许可的工厂生产,受托方候选乐心医疗或推动埃微 / Veepoo 走受托资质。拿证后融资叙事直接对标 RingConn(消费级起量 → NMPA 二类证 → 医疗机构合作)与乐心(ODM 现金流 → 医疗证 → 慢病管理服务),两条都是已验证的珠三角路径。戒指作为 2.5 阶段第二形态,复用同一套注册与质量体系。
